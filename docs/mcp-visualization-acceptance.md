## 检查项目

- 48 次评估使用 48 个不同的真实运行快照；逐行核对 `eval_row.snapshotId`、清单 `runId` 和 `summary.runId` 相同。
- 快照内的面差原值与评估行指标逐值一致；输入身份标记 `unchangedDuringRun:true`。
- 前 20 个样本按面差绝对差排序，独立从原评估行计算排序并核对；第二页剩余 4 项，无重复或遗漏。
- 最大变化样本通过快照直接下钻，展示双轮廓、拟合圆、基准线、间隙/面差线段和量测数值；并排与叠加共用坐标范围。
- 未重新运行算法即可在新 MCP/HTTP 进程读取旧快照。不同输入的 A/B 被拒绝，缺少坐标变换的叠加被拒绝。
- 单独运行两个错误布局样本验证执行失败：失败快照仍存在，缺失拟合及量测输出明确列出，失败筛选返回两项。
- 不设置 `LYFLOW_WORK_DIR` 时，默认启动器、CLI 评估、HTTP 读取仍共享持久目录，单样本评估后可以直接查看。
- 实际 PNG 目视检查：圆保持等比例，较浅高度在上方，图例与量测可读；指标曲线按各自轴范围显示。未使用 Python 绘图。
