# 编辑器操作指南

[文档首页](README.md) · [快速开始](getting-started.md) · [参数配方](recipe.md) · [验证入口](testing.md)

本页说明当前编辑器的操作方式。界面的 `?` 或左侧「帮助」可查询完整快捷键；按键和鼠标说明由 [keymap.ts](../packages/editor/src/lib/keymap.ts) 统一定义。输入框有焦点时，普通字符和输入编辑键优先归输入框。

## 工作流与文件

| 区域 | 用途 |
|---|---|
| 顶部标题栏 | 切换、关闭工作流标签，`＋` 新建；双击标签或标签有焦点时按 F2 重命名。 |
| 顶部工具栏 | 保存、配方切换、撤销/重做、算子库管理及运行控制。 |
| 左侧「工作流」 | 新建、打开文件、搜索、查看已打开文档及最近文件；不用时可收起。 |
| 左侧「节点 / 参数 / 日志」 | 算子库、全图参数、日志与诊断等工作区入口。 |

「保存」主按钮保存当前图及有改动的配方；旁边下拉提供「另存为」和「重命名」。文件快捷键为 `Ctrl+N`、`Ctrl+O`、`Ctrl+S`、`Ctrl+Shift+S`。首次保存或另存为取消时，现有内容保留。

每个工作流独立保存文档、参数配方、撤销/重做、视口及运行结果。标签小圆点表示图或配方有未保存改动；打开已在标签中的同一路径会切换到该标签。关闭未保存的标签或窗口时，可选择保存、不保存或取消。

桌面标题栏空白区域可拖动窗口，双击空白区域最大化或还原。双击标签仅重命名工作流；画布选中一个节点后按 F2 则重命名节点。备份恢复只用于未触碰的初始工作区，不会替换等待期间产生的新编辑。

## 画布、选择与搜索

| 操作 | 效果 |
|---|---|
| 左键拖空白处 / 中键拖 | 平移画布。 |
| 滚轮 | 缩放画布。 |
| Ctrl + 左键拖 | 框选节点。 |
| Ctrl + Shift + 左键拖 | 追加框选到已有选区。 |
| Ctrl / Shift + 单击节点 | 加选或取消该节点；拖动一个已选节点可移动整组。 |
| 双击空白处 / Tab / Space | 搜索并添加算子；控件有焦点时 Tab、Space 仍归控件。 |
| 右键节点、连线或空白处 | 打开对应菜单；空白处可添加算子、全选、整理布局及适配视图。 |
| Ctrl+L / Ctrl+Shift+F / F | 整理布局 / 适配全图 / 适配选中节点。 |

左侧算子库和画布搜索使用同一套匹配规则：支持中英文、全半角、缩写、多词跨字段匹配及有限英文拼写容错。可按名称、ID 和关键词查找；从端口拖线后打开搜索时，会优先展示能接上的算子。

`Ctrl+F` 查找现有节点，包括内联子图内部；支持 `op:`、`is:muted`、`is:error`、`is:ng`、`is:margin` 等条件。回车定位，`Alt+Enter` 选中当前层级命中的节点；库算子的只读内部不列入搜索。

## 连线与编辑

从输出端口拖向输入端口建立连线；不兼容类型或会成环的连接会被拒绝。拖线松在空白处可搜索新算子并自动接线；松在节点身上时，仅在有唯一兼容端口的情况下自动连接。

拖动输入端的线头可以改接；把节点或面板中的算子拖到已有连线上，可在兼容端口组合唯一时插到中间。右键连线可插入 Reroute、插入算子或删除连线。双击连线用于查看数据。

常用编辑键为 `Ctrl+Z` 撤销、`Ctrl+Shift+Z` / `Ctrl+Y` 重做、`Ctrl+A` 全选、Delete 删除。`Ctrl+C/X/V` 复制、剪切、粘贴节点；`Ctrl+D` 原地复制，`Shift+D` 复制并保留输入连线，便于比较两组参数。复制的节点可跨工作流粘贴；在文字区域选择文本时，复制/剪切仍处理文字。

双击节点标题或单节点选中后按 F2 改名；`Ctrl+E` 折叠，`Ctrl+M` 静音。`Ctrl+Delete` 尝试删除节点并接通上下游，只有连线兼容时才会接通。

## 运行与调试

- 顶部「运行」或 F5 运行整图；Esc 发出取消。运行中的「重跑」沿用原来的运行范围。
- 框选多个节点后，浮动操作条的「运行选中」或 `Shift+F5` 运行所选节点及必要上游，不运行未选中的下游。所需输入不会因为框选而被忽略。
- 节点标题右端运行按钮执行该节点及缺结果或过时的上游；悬停可查看运行范围。`Shift+单击` 强制重算该节点。
- 节点右键可运行到此节点、强制重算或仅运行此节点。「仅此节点」依赖已有且可用的上游结果，上游不足时不可用。
- 修改参数后，未更新的结果会标为过时；缓存命中与实际执行范围由引擎计划决定。节点底部点数和耗时是辅助信息，悬停可查看详细值。

自动运行开着时，提交参数改动后会补正式运行；拖动中的抽稀预览不替代正式结果。关闭自动运行后，可在交互预览后按 F5 获取正式结果。预览点数控制只影响预览范围，不代表完整数据数量。

错误会标在节点、参数控件及诊断抽屉中。点击错误条目或用 `F8` / `Shift+F8` 定位，包括内联子图内部错误。`Ctrl+反引号` 打开或收起日志与诊断抽屉。

## 参数与配方

选中节点在右侧检查器编辑参数；多选同一种算子时，可一起修改参数，不同值显示为「不同」。参数右键可重置、复制值、粘贴值和复制路径；数值框可输入算式及相对改法，越界与取整按参数规格处理。

数值框水平拖动改值，Shift 加快、Alt 放慢；一段拖动合为一条撤销。文字或数值输入按 Enter / 失焦提交，Esc 撤回未提交内容；F5 和保存会先提交当前框内的值。路径参数可粘贴路径，宿主提供文件选择器时显示浏览入口。

左侧「参数」或 `Ctrl+Shift+P` 打开全图参数面板，替代节点检查器；可拖分栏改宽、最大化，并按参数名、标签、节点、值及诊断筛选。参数行可纳入图参数或配方；面板还包含配方矩阵和配方管理。

工具栏配方下拉选择「基础」或命名配方。配方覆盖、默认值、失配报告、导入导出及 CLI/宿主选择规则见 [参数配方](recipe.md)。有阻止运行的失配时，先修复失配再运行。

## 预览、对比与测量

选中节点后，右侧预览显示其输出；只有几何输出时可用上游点云或图像作为底图。预览支持 3D 点云、正交 2D、图像及值信息，显示方式随输出类型变化。

点云预览中，左键拖旋转、右键拖平移、滚轮缩放；正交 2D 下左键拖为平移。双击显示的点，把视角转心移到该点。鼠标位于预览上时，`1/2/3/4` 切换俯视、前视、侧视、轴测。工具栏可修改着色、色带、范围及点大小，并导出 PNG。

`P` 钉住当前预览：选择其他节点不切换预览，同一节点重跑仍更新。`Shift+Space` 最大化或还原预览，Esc 也可还原。

「对比」或 `Ctrl+Shift+D` 进入 A/B 对比；也可右键节点设为 B 基准。A 跟随当前选中或钉住节点，B 可冻结改参前的快照。两侧共用视角及着色，差异表显示同名字段的 A、B、Δ（A−B），点数与包围盒采用全量统计。对比时不能拖 ROI 框，进入拖框会先退出对比。

「测量」或 `M` 开关主预览的点选测距：第一次点显示 P1 坐标，第二次显示 P2、距离和坐标差，第三次重新开始。只吸附到实际显示的点；距离以米和毫米展示，2D 剖面另外显示 XY 平面距离。对比时可在 A、B 两侧分别选点。换节点清除点位；同一节点重跑保留点位但提示云已更新。它是交互读数工具，不把测量结果写回算子参数。

图像预览支持缩放、悬停读取像素和几何叠加；声明像素 ROI 的参数可进入拖框编辑。ROI 的坐标、单位及底图契约见 [算子描述](operator-manifest.md)。

## 连线查看器、子图与库

双击连线打开浮窗查看源端口数据，不会自动运行图。查看器支持点云、正交 2D、张量图像、Image、键值与原始 JSON；窗口可拖动、多开和锁定已有结果快照。当前最多 6 个查看窗口，其中 WebGL 窗口最多 4 个；没有运行需要取消时，Esc 关闭最前面的查看窗口。点云查看器有独立的测量开关，`M` 键仍控制主预览。

`Ctrl+G` 将选区合成子图，`Ctrl+Shift+G` 解散，双击子图或 `Ctrl+Enter` 进入，Esc 返回上一层。子图可提升参数并保存为库算子；库算子可展开为内联子图，再独立编辑。图格式见 [GraphDoc](graph-doc.md)，目录配置见 [库算子目录](library-dirs.md)。

工具栏「算子库」管理原生库目录及 Python 节点。修改 Python 脚本或依赖后需手动刷新，配置和数据接口见 [Python 自定义节点](python-nodes.md)。

宿主启用拓扑锁时，结构编辑和节点/工作流管理入口隐藏或受限；左侧参数、日志、帮助仍可用。宿主能力、只读约束及关闭动效设置见 [嵌入指南](embedding.md)。
