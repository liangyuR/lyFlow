## 迁移原则

M1–M4c 的实现暴露出几类系统性膨胀：迁移规则写进 core 并在每次加载时运行、旧实现等到最后才退役、同一不变量逐层重复校验、无消费者的来源元数据、以源码指纹和合并凭证充当验收证据。以下原则对 M4d 起的所有切片生效，与旧表述冲突时以本节为准。

1. **图迁移离线一次完成。** 旧图升级只由 `lyflow migrate` 显式触发并写回文件；GraphDoc 不携带活动升级请求，加载与执行路径不运行升级。读到遗留的 `contractUpgrade` 或已退役算子时只给出可操作诊断（提示运行 `lyflow migrate`），不在内存中改图。
2. **迁移规则归场景包所有。** 某个 solution 的旧 ID 白名单、参数改名与单位换算写在该 solution 内，通过迁移注册接口挂载；core、bridge、编辑器不出现任何 solution 算子 ID 或业务常量。同一规则只实现一份，其他宿主调用它而不是各自重写校验。
3. **等价性按容差 + 场景金标准验收。** 默认以声明的数值容差和真实场景基准帧证明行为不变。只有在清单中逐项写明理由的项才要求逐位一致；不为逐位一致保留 float/double 两份核或旧算法分支。
4. **随切片退役。** 一个切片替代了旧实现，就在同一切片删除旧注册、旧源文件、适配壳及其测试。不允许留下未编译的源文件、未被调用的注册函数、同一 ID 的两份注册，或只为旧路径存在的参数分支。M7 只负责跨宿主切换和真正需要用户配合的退役项。
5. **校验只做一次。** 执行器已保证的事项（端口类型、Profile 合法性、枚举取值、参数类型与范围）算子内不重复；内核只校验自身输入不变量。不对算子刚生成的结果再做哈希或逐槽比对来"自证"。
6. **元数据必须有消费者。** 新增的来源、上下文或质量字段须写明读取方（编辑器、宿主、下游算子或测试以外的 SDK 消费者）。没有消费者的字段不进入端口契约；为保持旧输出结构而填占位值、重复值的字段在下一个契约版本删除。
7. **分层不倒置。** core（含 `core/cmake`、`core/tests`）不编译、不引用 `solutions/` 下的源码与测试；场景测试放在对应 solution 内。
8. **验收证据不入库。** 清单只记录 `id → currentPack / targetPack / action / wave`；源码指纹、行号、PR 号、CI run、审查回执等写在 PR 描述里，不写进仓库文件、脚本或测试。CI 只用实际 manifest 核对 ID 全集与包归属。
9. **测试按 [测试约定](testing.md)。** 在能覆盖行为的最低一层测；release/e2e 层不断言算法数值；同一判据不在内核、包、SDK 三层重复；fixture 不保存仅 id/name 不同的变体；不写拿 fixture 自身字段比常量的自证断言；增删测试同步更新测试地图。

## 每次迁移的执行清单

1. 锁定原ID/版本、参数默认值、端口、单位、坐标系、输入顺序和失败诊断；记录直接后端与当前传递依赖。
2. 先抽可独立链接的内部算法/校验接口，再迁算子注册；不能让一个算子通过执行另一包的节点绕过真实C++依赖声明。
3. 冻结旧→新ID、包、版本及数据映射。纯归属移动不改ID；拆分节点、改变端口/单位时在所属 solution 内提供离线迁移规则和容差内的等价性说明。
4. 同步直接消费者、场景图、Bundle/Record schema、片段、库组合和宿主注入。不能只有新生产者没有匹配消费者。
5. 校验正常、空输入、无效/退化、单位/帧不符、取消及只读输入，但只在负责该不变量的那一层校验和测试。
6. 核对缓存键的算子版本、模型指纹、场景图与内部实现身份；改变数值契约时提升版本，不沿用旧结果缓存，也不为旧版本保留并行缓存分支。
7. 单独启用目标模块构建，检查导入表、安装文件及许可证，证明轻量配置没有PCL/OpenCV/ORT等意外依赖。
8. 删除被替代的旧注册、源文件、适配壳、测试和文档引用；用"未编译源文件为零、未调用注册函数为零"自检。
9. 更新清单中该项的归属/状态，验收证据写在 PR 描述中。

## 重点风险与对应验收

| 风险                                           | 验收                                                                                                                  |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 毫米/米混用或XZ/XY反射被当旋转                 | 单位/轴映射夹具、手性检查、原始→公共→原始往返；未知元数据拒绝连接/计算                                                |
| DTS毫米几何载荷保留默认Meter标签               | seal_dome/pick_metal/seal_root/flush的旧版本夹具按来源适配0.001，独立核对Measurement.unit；不能仅凭unit=Meter跳过转换 |
| 清洗丢失1280槽、排序打乱轮廓、索引不再指向原云 | NaN/缺槽/双层重叠/非单调采样，附加通道及sourceIndices往返；模型前后长度一一对应                                       |
| TLS替换RANSAC、固定半径/先验/重试被合并掉      | 分方法固定夹具、短弧/退化/双相机异常与质量字段回归，不以名称相同代替算法等价                                          |
| 纯几何距离误当作间隙或面差定义                 | 独立基准和方向、signed/unsigned、左右交换、投影/采样边缘、端点/圆边界分别验证                                         |
| 有效性、胶路合格和生产许可混为一谈             | 未测得保持无效及reason；候选可见性不改变正式runs/present/coverage或最终业务判据                                       |
| 包变轻只存在于文档                             | core-minimal、profile-metrology、adapters-only、portable-generation独立构建与实际导入表检查                           |
| 旧库图表面加载成功但丢端口/参数                | `lyflow migrate` 迁移夹具覆盖编辑器与headless；缺包/旧版保留节点连线，不能迁移的项明确拒绝执行                        |
| 相同ID内部实现变化复用旧缓存                   | 明确版本/图/模型指纹变更，旧缓存不命中新语义；迁移后重复运行与干净运行一致                                            |
| SDK通过但依赖开发目录或私有头                  | 独立安装目录的C++17/Rust/CLI消费者，源码树外运行；不得依赖另一包的私有实现路径                                        |
| 兼容代码只增不减                               | 每个切片自检未编译源文件与未调用注册函数为零；PR 描述列出删除的旧实现                                                 |

最终编辑器测试继续按功能契约保持100项以下，保留主线覆盖并按必要场景合并组织；新增迁移回归不能靠skip、提前return或删除错误分支把数字压低。原生、Python和SDK测试单独统计，静态文档检查不能代替这些执行证据。

## 规划检查与后续维护

清单只核对两件事：实际 manifest 的原生 ID 全集与清单一致，每项的当前包归属与 manifest 一致。端口、参数、源码内容的变化不触发清单变动；契约变化由对应包的测试和版本号承担。字段与检查方法见[逐算子清单](operator-package-audit.md)。

当新增算子、改变归属或退役 ID 时，同一 PR 更新清单对应项。
