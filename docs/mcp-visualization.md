## 从运行结果到图片

先保存当次运行的输出快照，再渲染。查看旧快照不触发重跑；重新采集或执行会得到新的运行身份。没有捕获的输出要明确说明，不能补跑后冒充原结果。

| 操作 | 工具与结果 |
|---|---|
| 捕获一次运行 | `run_graph` 成功捕获后返回 `snapshotId`；`eval` 保存样本当次运行的可视化输出 |
| 查看单帧 | `view_outputs` 指定快照及节点端口图层，返回 PNG 图片内容、高清 PNG、SVG 和 SceneSpec |
| 比较 A/B | `compare_views` 指定两份快照与各自图层映射，核对输入身份并统一视口 |
| 浏览批量结果 | `view_evaluation` 按指标或相对基线差值排序、筛选和分页，用记录中的 `snapshotId` 下钻 |

仅在 `snapshotStatus=ready` 且 `snapshotId` 非空时读取持久快照。超时、取消或捕获失败可能返回 `snapshotId:null`、`snapshotStatus:pending/unavailable`，失败原因可见 `snapshotError`；不能直接拿 `runId` 冒充已经捕获的快照。

工具完整参数以 MCP schema 为准。PNG 使用共享 `@lyflow/visualization` 渲染器，由系统 Edge/Chrome/Chromium 的 headless 模式生成；可通过 `LYFLOW_BROWSER` 指定可执行文件。不依赖 Python 重画，也不在渲染时重新拟合几何。

## 坐标、单位与真实性

- 场景显式声明坐标系、单位、投影轴和纵轴方向。未知变换的图层不能直接叠加，不根据数值范围猜坐标轴。
- 圆、线段和端点来自算子输出；无限直线裁剪到视口只属于显示处理，不改变算法结果。
- 点云原始点数、可显示点数和降采样数量需要区分。空输出、非有限值、执行失败和未捕获输出不是同一状态。
- A/B 对比要核对输入身份，统一视角、坐标范围和颜色尺度，并显式映射对应端口。几何位移与产品量测差异分别检查。
- 执行成功、定位/量测有效和产品 OK/NG 分开解释，判据由业务宿主定义。

归档轮廓若使用 `x=u, y=h, z=0`，应按实际格式给 `gap.load_profile_pair` 设置 `layout=profile`；它输出传感器 XZ，经过 `gap.to_measurement_frame` 后才是测量 XY。几何通常以米表示，量测数值读取其自身 `unit`，不能直接拿像素或投影轴替代物理坐标。

## 复验方式与边界

在独立工作目录固定图、参数、输入、模型/模板、标定及运行库身份，保存基线和候选结果，再对差异大的样本下钻检查实际点云、拟合几何、ROI 和量测线段。原始数据保持不变；不要只凭缩略图得出算法准确率结论。

结果快照、图层、坐标变换与渲染属于 LyFlow；业务仓库负责端口映射、产品坐标、量测含义和合格判据。平台回归、离线样本和生产验收的范围分别记录，不能相互替代。当前检查入口见[测试地图](testing.md)，发布门禁见[发包指南](deployment/packaging.md)。
