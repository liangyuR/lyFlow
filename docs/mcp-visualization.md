# MCP 可视化与离线复测

## 目标与边界

运行结果必须先保存，再渲染。图片中的点云、拟合几何和量测来自同一次执行，查看旧结果不得触发重新执行。重新采集会产生新的运行和快照。

通用能力属于 LyFlow：结果快照、图层、坐标变换、渲染、A/B 对比、批量结果浏览与 MCP 图片交付。业务仓库负责节点端口映射、单位与坐标约定、指标含义和产品判据。

## 四阶段验收约束

| 阶段 | 必须证明的行为 |
| --- | --- |
| P1 快照 | 保存当次输出；修改输入、重新运行或服务重启后旧结果不变；未保存输出明确说明原因；保存策略和配额可控。 |
| P2 单帧 | 点云、图像、实际几何、ROI 与量测可出图；共享编辑器渲染逻辑；无 GPU 可出 PNG；图片和场景均可追溯。 |
| P3 对比 | 核对输入身份；统一视角、坐标范围和颜色尺度；支持显式端口映射；参数及量测差异可检查。 |
| P4 批量 | 同次评估保存可视输出；按指标排序、筛选失败样本和分页；缩略图可下钻原快照；重启后仍可查阅。 |

## 坐标与数据真实性

场景声明坐标系、单位、横纵轴和纵轴方向。不同坐标系必须提供显式变换；未知变换不能直接叠加。坐标轴不能根据数值范围猜测。

几何显示使用算子输出的圆、线段和端点。渲染器不得重新拟合；无限直线裁剪到视口属于显示处理，不能修改算法结果。原始点数、可显示点数和降采样数量应可检查。空输出、非有限值、执行失败与未捕获输出必须区分。

执行成功、定位或量测有效、产品 OK/NG 是不同状态，不应互相替代。

## 现场数据验收

本轮选择用户授权的 DTS 天幕 KUN10 L1 数据。原始数据与图不做修改，在独立验收目录配置输入路径、模型与模板路径。

归档 PCD 使用 `x=u, y=h, z=0`，`gap.load_profile_pair` 必须显式设置 `layout=profile`；加载后返回传感器 XZ，`gap.to_measurement_frame` 后为测量 XY。几何输出以米表示，量测数值的单位以自身 `unit` 为准。显示高度向屏幕下方增加，浅处在图上方。

验收任务：运行基线与参数变体，展示变化最大的 20 个样本，打开其中一个样本查看双轮廓、实际拟合圆、基准线及量测线段。不得使用 Python 重画算法结果。

本文件定义验收要求；是否通过以当前修订的实际命令、运行结果及图片检查记录为准。

当前实现的真实数据与自动回归记录见 [验收记录](mcp-visualization-acceptance.md)。
