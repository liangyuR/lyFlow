## 端口与表达式

输入 `a`..`h` 均为可选 `std.Value.v1`，实际使用的值必须是 number 或 boolean。表达式参数 `expression` 为多行文本，默认 `(a+b)/2`；输出 `value` 仍为受校验的 `std.Value.v1`，可连接已有比较、列表或条件选择节点。未连接且实际取值的变量产生指向该端口的诊断，不隐式取零。

| 语法 | 定义 |
|---|---|
| 数字与变量 | 十进制、小数、科学记数；变量仅 `a`..`h`，布尔常量 `true`、`false`。 |
| 算术 | `+ - * / ^`、括号、一元 `+ -`；幂右结合。 |
| 比较 | number 的 `== != < <= > >=`；boolean 仅 `== !=`。数值相等为 float64 精确比较。 |
| 逻辑 | `! && \|\|`，仅接受 boolean，不将数字隐式转换为真假。 |
| 条件式 | `condition ? then : else`，右结合；条件必须为 boolean。 |
| 单参函数 | `abs`、`sqrt`、`floor`、`ceil`、`round`。 |
| 双参函数 | `min`、`max`、`pow`。 |
| 三参函数 | `clamp(value, lower, upper)`，下界不得大于上界。 |

优先级从低到高为 `?:`、逻辑或、逻辑与、相等比较、大小比较、加减、乘除、一元符号、幂、基本值/函数/括号。除幂和条件式外，二元运算按左结合；连续大小比较不具有 Python 链式比较语义，应写 `a < b && b < c`。`round` 的半数按远离零舍入，例如 `round(2.5)=3`、`round(-2.5)=-3`。

不支持字符串、成员/下标访问、赋值、循环、文件/网络调用或任意宿主代码。函数名与参数个数必须匹配白名单。需要近似相等时，可显式写 `abs(a-b) <= c`，其中 `c` 使用同单位容差；现有 `value.compare` 仍提供绝对/相对容差组合。

## 单位、短路与调度

- 加减、数值比较、`min`/`max`/`clamp` 要求单位逐字一致；不隐式转换 `m`、`mm`、`px`。
- 乘法至少一侧无单位；除法允许无单位除数或相同单位相消。单位字符串不被当作可任意相乘的量纲代数。
- `abs`、`floor`、`ceil`、`round` 保留单位；`sqrt`、`pow`、`^` 只接受无单位数值。
- 解析会验证整条表达式。未取分支中存在未知标识、函数、错误参数个数或非法语法仍然失败。
- 求值阶段 `&&`、`||` 和 `?:` 仅计算选中的分支。`false && (1/0 > 0)`、`true ? 2 : a` 可成功；被跳过的除零、定义域和未连接变量不触发诊断。条件分支的结果类型和单位由实际选中值确定。
- 这只是表达式内部短路，连接到 `a`..`h` 的上游仍按现有执行器正常调度。避免计算图中的未选上游应使用 `flow.select` 的现有惰性端口，不能把表达式短路当作上游失败隔离。

## 资源、失败与验证

表达式源码最多 4096 字节，AST 最多 1024 个节点，解析的表达式嵌套最多 64 层，AST 从根到叶最多 64 个节点；过长的左结合运算链同样受树深度约束。没有无界循环或递归函数，解析和求值都检查取消。输入值沿用现有版本、大小、深度和有限值校验；结果不会改写上游值。

图校验和运行计算共享同一语法解析器；图校验不要求可选变量已连接。语法、未知标识/函数、参数个数、非法数值字面量及资源超限报告 `bad_param`，指向 `expression` 并提供从 1 开始的字节位置。缺少实际使用的输入、类型/单位不符、除零或数学定义域问题报告 `bad_input`。数字字面量的溢出/不可表示下溢拒绝；运算结果按既有 float64 舍入，非有限结果拒绝。

实现与契约回归入口分别为 [expression.cpp](../packs/std-value/ops/expression.cpp) 和 [test_expression.cpp](../packs/std-value/tests/test_expression.cpp)。回归覆盖优先级、函数/单位、完整语法、短路、恶意或资源超限输入、取消及真实调度器行为。[完整示例](../examples/p2-expression.lyflow.json)将均值、上限判定和 `flow.select` 组合，默认12mm/14mm得到均值13mm，超过15mm上限时选回上限。相同 GraphDoc 由 CLI、C ABI 与 C++ SDK 验证；具体结果以当前 PR 对应修订的检查报告为准，不以配置界面或单次运行代替完整验收。
