## 改动范围

| 项目 | 结果 |
|---|---|
| 外部文件缓存身份 | 所有非空 Path 参数在原参数和 externalKey 之外，追加按 baseDir 解析的绝对路径身份；用 weakly_canonical 处理符号链接。不同目录下同名、同大小、同 mtime 的文件不再共键。 |
| Tensor 统计 | 不可变 Tensor 的 min/max/mean 首次扫描后共享缓存；不同 Data 的预览 scale 单独生成。 |
| 结果仓复用 | 锁内完成载荷快照、索引、计数和淘汰，锁外生成元信息，避免缓存命中时持全局锁扫描大张量。 |
| ONNX 会话 | 缓存最多持有 8 个最近使用的会话；shared_ptr 保留活跃调用，同路径新指纹成功加载后回收旧指纹。慢构建不阻塞命中，资源在缓存条目锁外析构。 |

ONNX 的输入复制和单会话推理互斥保留。会话数上限不等于内存硬上限，活跃调用可暂时保留额外会话。
文件指纹仍使用 size/mtime，保留这两项元数据覆盖同一路径的文件内容不在本轮保证范围内。
Path 参数的缓存键变化会使旧结果重新计算一次。产品版本、算子版本、Data 布局及 C ABI 未改动。

## Tensor 元信息微基准

同一台 16 逻辑线程 Windows 机器，MSVC 14.44.35207，`/O2 /MD /EHsc /std:c++17 /utf-8`。
新旧源码使用同一 benchmark，输入为 4,194,304 个 float32、16 MiB 的不可变张量。
编译与测试结束后，按 baseline、candidate、candidate、baseline、baseline、candidate 顺序串行运行，
每轮 101 次；下表是三轮各自 p50/p95 的中位数，单位 ms。

| 元信息读取 | 基线 p50 | 候选 p50 | 基线 p95 | 候选 p95 |
|---|---:|---:|---:|---:|
| 首次统计 | 3.7961 | 3.7123 | 4.7904 | 4.3817 |
| 同一 Tensor 重复读取 | 3.8026 | 0.0012 | 4.8801 | 0.0027 |

计时仅包括 `Data::valueJson()`，不含 Data 构造、张量分配、推理、IPC 或整图执行。
“首次”表示统计缓存未建立；所有轮次复用张量内存，不表示 CPU 冷缓存。
每次结果均与首次结果逐字相等，新旧全部轮次 checksum 均为 20200。
本数据证明重复统计扫描已消除，不用于推算整图加速比例或结果仓争锁改善幅度。

复跑当前源码：

```powershell
pwsh -NoProfile -File scripts/bench-tensor-metadata.ps1 -OutputDir build/metadata-current
```

准备旧源码快照后，用同一脚本指定 `-SourceRoot <快照目录>`；比较前固定机器负载、元素数量和迭代次数。
脚本在输出目录保存 `result.json`、源码 SHA-256 和编译日志。本次三轮结果位于
`build/round1/metadata-comparison.json`，构建与回归日志位于 `build/round1/`，这些本地证据不纳入 Git。
