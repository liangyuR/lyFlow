# ADR-0032：不可变原生帧与宿主结果交付

状态：已采纳，开发版本1.3.12。

引擎内容缓存用于相同输入复用，不能承担有顺序、容量及重置语义的FIFO。旧快照也没有完整Tensor/Indices回读，不能用重跑源图冒充录制回放。

采用独立不可变Frame所有权及只读ResultStore视图，复用既有原生getter；Frame与Session不依赖缓存存活。单文件归档分离小JSON清单和连续原生二进制，保持通道、位深、scale及无效数值。加载前检查范围、版本、预算；重新分配点云身份，只对标准契约声明的引用重绑。

FIFO放在宿主边界，配置会话、字节/数量预算、满队列策略、时间顺序及结构变化策略；入队取消/失败不提交，reset分配新代次。录制保存实际图参数、展开源和原注入；默认只读回放，明确要求时才重新执行算法。

外部发布使用显式端点和版本化完整帧，只有匹配ACK才确认副作用，不自动重发未确认交付。日志格式、路径、首项/全部、归档和覆盖策略均由宿主显式选择。不声称兼容外部私有协议。

C ABI只增加可选函数及opaque句柄，不扩展现有选项结构或改变1.3系列必需符号。C++/Rust句柄保留动态库生命周期；旧运行库仍可加载，新能力按需报缺失。详情及资源上限见[P6指南](../p6-examples.md)。
