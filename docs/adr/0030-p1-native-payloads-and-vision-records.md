# ADR-0030：P1 原生载荷与视觉元数据

状态：已采纳

P1 扩展点云集合、位姿、标定、模板与检测。继续使用现有 Data/Record/Tensor/Indices，避免为每个领域对象增加 C ABI 类型；依赖仍局限在对应算子包。

点云集合以共享原生 PointCloud、原生 Indices 与有界 `cloud.Groups.v1` 分段元数据共同表示。云身份、通道长度、范围和偏移必须一致，不把点或索引数组装入 JSON。图像、模板像素和推理张量同样保持原生载荷。

小型对象使用版本化 Record：`vision.Pose2D.v1`、`vision.Pose3D.v1` 及其集合、`vision.CameraCalib.v1`、模板/检测映射描述。消费者验证类型、版本、单位、坐标系、有限数值、大小和集合唯一 ID；不能仅凭 JSON 键名猜测对象。集合限制 4096 项、1 MiB、深度 16。位姿变换要求明确源/目标坐标系；像素尺寸不能隐式解释为米或真实三维抓取区域。

三维配准与剖面质量按实际交付的 float32 Transform/Line 重新评估，避免双精度求解通过而原生输出精度不达标。退化、未收敛和质量不达标应返回诊断。局部多起点 ICP 不等于全局配准；PCA 包围盒不等于最小体积包围盒。

模型链拆为预处理、现有 ONNX 推理、专用解码，显式声明签名；YOLOX、常规 YOLOv8/11 与 YOLO26 端到端输出不能靠形状模糊猜测。权重作为外部固定资产，不进入运行库；SDK 提供准备脚本和许可说明。

本次不新增 Data::Kind、ABI 符号或 Transport 方法，产品补丁版本保持 1.3 系列 ABI 兼容。具体模式、源码分析与剩余缺口见 [补齐计划](../operator-completion-plan.md) 和 [能力对照](../operator-coverage.md)。
